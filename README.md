# 供应商管理系统 · 骨架版

当前仅搭建网站框架，**不含任何业务内容与数据**。

## 目录结构

```
supplier-system/
├── index.html        # 单页入口（侧边栏 + 顶栏 + 内容容器）
├── css/style.css     # 基础样式
├── js/app.js         # Hash 路由 + 空状态渲染
└── README.md
```

## 已就位的模块（均为空占位）

- 工作台
- 供应商管理
- 准入审批
- 绩效评估
- 合同管理
- 系统设置

## 本地预览

在该目录下启动任意静态服务器，例如：

```bash
npx serve .
# 或
python -m http.server 3000
```

然后浏览器打开 `http://localhost:3000`。
