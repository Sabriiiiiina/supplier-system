# 供应商管理系统

面向美术/游戏外包的供应商全生命周期管理系统，纯前端静态实现，数据存浏览器本地（localStorage）。

## 在线访问

**https://sabriiiiiina.github.io/supplier-system/**

## 功能模块

| 模块 | 说明 |
|---|---|
| 工作台 | 统计卡片（总需求/进行中/供应商/待结算）、进行中需求看板（按状态分列）、全局搜索 |
| 供应商库 | 供应商入库卡片、自助入库链接、合作状态自动判定 + 手动覆盖、关联需求单与合同 |
| 发包管理 | 需求单下达与全字段管理、检索筛选排序、状态流转、按项目分组权限 |
| 合同管理 | 合同台账（供应商/是否签署/双方签约主体/起止日期），新增供应商自动同步 |
| 结算 | 需求单自动同步、完成度手填、实际结算金额自动计算、结算单/发票附件、一次性确认结算 |
| 数据分析 | 自定义图表（柱状/环形/指标卡，维度×指标可配） |
| 系统设置 | 业务人员名单、项目分组权限、字典配置（项目/分类/品类） |

## 业务字典

- 供应商分类（5 类）：美术、素材、音频、外派、本地化
- 项目（6 个）：MC、Nova、MF、C、S、K
- 需求品类（8 个）：角色原画、场景原画、角色动画、场景动画、角色模型、场景模型、图标、UI

## 目录结构

```
supplier-system/
├── index.html        # 单页入口
├── css/style.css     # 样式（含浅色/深色主题、界面设计器）
├── js/app.js         # 应用逻辑（数据层 + 7 模块 + 权限 + 全局搜索 + 设计器）
├── standalone.html   # 单文件版（CSS/JS 内联，双击可离线打开）
├── build.js          # 生成单文件版的构建脚本
├── server.js         # 本地预览用静态服务器
└── README.md
```

## 本地预览

```bash
# 方式一：直接双击 standalone.html
# 方式二：启动静态服务器
npx serve .
# 或
python -m http.server 3000
```

## 数据说明

纯前端实现，数据保存在当前浏览器的 localStorage 中，不同设备/浏览器之间不互通。如需跨设备实时协作，需接入后端（飞书多维表格 / 轻流 / 腾讯云 CloudBase 等）。
